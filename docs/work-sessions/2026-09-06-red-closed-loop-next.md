## Mission check

- **Capability:** make several successive completion choices from refreshed semantic state,
  retaining actual specimens and responding to changed resources or failed skills.
- **Learned authority:** the fitted goal scorer selects supported semantic goals inside a bounded
  development episode. Existing deterministic skills enforce movement, battle and menu mechanics.
  The observer verifies outcomes; it must not silently replace the selected goal.
- **Transfer test:** first use the four already-declared disjoint Red paired roots descriptively.
  Four non-tied wins are not a powered superiority result. Keep portable features/actions intact;
  Crystal is a later transfer test, not an extra prerequisite for starting Red play.
- **Cheapest falsifier:** a short episode with at least three actual model-chosen goals, a fresh
  observation after each, and an independently refreshed collection ledger. A changed situation
  must change the available choices or produce an explicit abstention, not a stale replay.
- **Time box:** one two-to-four-hour development session, with the first integrated short episode
  attempted as early as practical. Reassess before expanding the engineering scope.
- **Stop condition:** no verified model-selected action, stale state between goals, unsupported
  progress claims, lost failure diagnostics, or a need to revive an old consumed trial. Report
  the exact blocker rather than opening another route factory or broad architecture project.
