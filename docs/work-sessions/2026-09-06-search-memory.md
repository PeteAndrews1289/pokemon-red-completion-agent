# Search-memory session

## Mission check

1. Capability: retain actual search effort across interruptions and distinguish the same exhausted
   opportunity from a changed collection target or encounter source.
2. Learned authority: prepare explicit history observations for the next versioned goal learner;
   the existing 32-example model is not silently treated as history-trained. No forced next goal.
3. Transfer test: identity-renamed, reordered and resumed ROM-free cases; no cross-game claim.
4. Cheapest falsifier: save/reload two different search records and check that only the matching
   opportunity receives its prior effort. Legacy saves must mean unknown history, not zero effort.
5. Time box: four hours maximum; reassess after 90 minutes without a useful next lesson.
6. Stop: no fabricated old history, feature aliasing, global acquisition blacklist, new teacher,
   consumed replay, or old-model promotion. Keep this the smallest maintenance unblock for the
   named memory-aware, two-alternative learning lesson.

## Next meaningful stage and percentage denominator

Stage: a memory-aware learner executes a useful alternative after an unsuccessful search, then
learns from that outcome in saved-state play. This is not full Red completion.

Five equally weighted acceptance items (20 percentage points each; not a time estimate):

1. Existing saved-state collect/fit/continue pipeline (already demonstrated with 32 examples).
2. Versioned, persisted opportunity-specific history with tested interruption/restore semantics.
3. A versioned learner consumes history, preserving the old corpus without invented labels.
4. Two genuinely useful, executable collection alternatives are demonstrated available.
5. A bounded sampled lesson and post-fit continuation demonstrate useful changed behavior.

Start: 1/5 = 20%. Only verified acceptance items advance this checklist. Report unfinished items
and the limits of the percentage explicitly; never turn it into a project-completion estimate.
