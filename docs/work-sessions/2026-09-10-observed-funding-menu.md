## Mission check

- Capability: expose resource-recovery choices that respect currently observed terrain.
- Learned authority: the learner still chooses goals; remove mechanically unreachable offers rather than force a destination. Maintenance unblocking the model 38 continuation.
- Transfer test: changed-terrain menus and old/new checkpoint mode combinations; no cross-title result implied.
- Cheapest falsifier: an old static funding offer remains reproducible during restore, but is absent from a new observed-mode menu when its route is closed.
- Time box: 45–90 minutes for versioned integration, focused tests and a bounded useful outcome if available.
- Stop: checkpoint mismatch, lost provenance, no executable alternative or uncertain terminal. No replay of consumed attempts, refunds or invented fits.

## Implementation verification

`--observed-trainer-funding` is explicit, requires trainer funding and is retained
in new episode metadata. Restore uses the parent's recorded mode (absent means false),
not the successor's setting; a successor cannot roll the mode back. Recovery and
recorded-support paths preserve it. The generic historical forward-goal flag set
and its hashes are unchanged.

New menus build current-map geometry before enumerating funding. They validate map,
position, readiness and stable observations. Other goals are not force-selected.
Execution still independently requalifies the same trainer before input.

297 focused menu, script, recovery, support and forward-goal tests passed. Actual
checkpoint compatibility and the prospective useful menu remain to be checked.
