## Design correction

The first implementation attempted one composed test but mocked registration, profile derivation,
the player observer and the inner preflight. Flash correctly rejected that as false confidence.
The test was removed rather than defended.

The accepted design groups real component checks under the
`nonconsuming_direct_rehearsal` marker. The direct registration check publishes only to an isolated
temporary test store. The real proposal/observer check uses actual capture and native-evolution
providers with only cartridge and IO seams substituted, and the real preflight evaluates the
result with two authorities without executing either binding.
