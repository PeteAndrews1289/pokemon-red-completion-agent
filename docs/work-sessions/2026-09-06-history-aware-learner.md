# History-aware learner session

1. Capability: distinguish measured search effort from missing history when choosing portable
   collection goals, while retaining experience already collected.
2. Learned authority: let outcome-fitted coefficients consume search context; do not replace the
   model with a hardcoded exhaustion penalty or forced alternative.
3. Transfer test: ROM-free renamed/reordered contexts and changed effort; real same-lineage Red
   evidence is training/integration only, not independent transfer.
4. Cheapest falsifier: old examples and model bytes must round-trip unchanged; a versioned
   successor must represent unknown versus tracked-zero versus exhausted history differently,
   and learn an effort-dependent preference from selected outcomes in a controlled test.
5. Time box: one session, at most four hours; reassess the useful-alternative gap after 90 minutes.
6. Stop: do not launch another acquisition-only loop. No invented historical effort, synthetic
   gameplay labels, overwritten corpus, development fitting, full replay, sealed Red or Crystal.

Implement and qualify the versioned representation and fit/policy path first. Inspect whether
existing skills expose two genuinely useful actions before any new bounded learning declaration.
If that prerequisite fails, report it directly rather than collect another repetitive search.
