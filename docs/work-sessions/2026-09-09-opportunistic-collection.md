# Opportunistic useful captures

## Working mission check

- Capability: capture useful missing living specimens and evolution precursors wherever the active cartridge declares them in a supported grass encounter source, without individual species routes.
- Learned authority: retain actual native goal/destination choices and incremental outcome fits; broaden the deterministic capture skill's eligible opportunities, not claim learned battle control.
- Transfer test: changed source tables, evolved wild forms and retained-specimen counts in ROM-free tests. Live evidence remains one correlated Red lineage.
- Cheapest falsifier: a useful noncanonical wild encounter must be captured, while a redundant specimen is skipped and the transformation dependency graph remains intact.
- Time box: two hours for the bounded implementation, tests and a new four-decision continuation batch; reassess rather than add architecture.
- Stop condition: stop at unexplained execution failure, specimen loss, invalid evidence, failed fitting or the declared batch limit. Preserve all consumed trials and costs; only verified search exhaustion can continue.

## Plan

1. Add an explicit prospective capture profile that derives local encounter offers from the cartridge and recomputes marginal collection demand. Preserve historical profiles and canonical transformation dependencies.
2. Test alternate-source captures, useful duplicates, directly caught evolved forms, redundant-capture rejection and profile retargeting.
3. Publish one tested executable change, then run a fresh bounded automatic batch from native91's authenticated endpoint. Report actual capture gains, fits and limitations; refresh the handoff and roadmap.

This is broadening an already functioning small-batch strategic learner. It is not the first optimizer run, end-to-end controller training, or an independent evaluation.

## Qualified implementation

retargeting rederives them rather than carrying stale encounter facts. Canonical
transformation dependencies and historical profiles remain unchanged. The capture
skill accepts any currently useful local specimen, not only the first species in
a canonical checklist. It retains the one-capture dose and all existing storage,
party and endpoint checks. Regional destinations remain the existing supported
ordinary-grass sources; this does not add fishing, Safari, trade or event mechanics.
