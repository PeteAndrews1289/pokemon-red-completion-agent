remain explicit automatic completions rather than fictitious policy decisions. The same
registry continues through Cerulean, Bill/Misty, Vermilion, Cut, Surge, Lavender and Celadon,

three early selections are singletons, neither mode tests ranking skill; the value of this run is
the durable clean-start handoff.
