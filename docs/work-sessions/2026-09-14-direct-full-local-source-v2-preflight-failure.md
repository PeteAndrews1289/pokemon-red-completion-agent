## Static diagnosis

source, and calls `map_id_for_wild_source` in the sort key. That resolver intentionally rejects
anything other than `wild:<Map>:grass`, so enumeration aborts before valid grass candidates can be
tried.

There is a second defensive gap: `_capture_corridor` resolves each candidate before entering its
`try` block, and its exception list does not include `RedLivingDexMultifamilyError`. A narrow repair
must preserve the grass-only resolver contract, filter incompatible encounter media at candidate
selection and make the corridor loop fail over safely if a malformed source still appears. It must
not relax water into the grass corridor.
