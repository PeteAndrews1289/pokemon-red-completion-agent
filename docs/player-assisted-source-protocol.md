# Approved short independent player origins

Pete approved the proposed independently initialized assisted-source protocol and
continued the steps3–4 goal after the source-provenance stop on September25.
This narrow exception supersedes the no-clean-power-successor restriction **only
for these short origins**. The retired supply factory, all consumed assignments,
sealed records, campaign saves and full-game teacher routes remain closed.

## Mission check

- Capability: supply authentic native situations for the existing whole-player
  lesson recorder and bounded model comparison, without replaying a campaign.
- Learned authority: none during source preparation. Later actors choose actual
  alternatives; setup edits, teachers and forced support are not model choices.
- Transfer test: one TRAIN origin and two separately initialized comparison origins,
  assigned before creation. All descendants inherit their origin and partition.
- Cheapest falsifier: capture one short TRAIN opening, validate its semantic state
  and durable controller transcript, then verify native lesson feasibility before
  preparing broad scenario variants.
- Time box:90minutes before reassessment. Each opening at most450macro attempts,
  80000frames and180seconds; no extension into a full-game teacher route.
- Stop: preserve failed attempts; no unrecorded replacement, relabeling, old-state
  transplant, speculative comparison access or renewed full campaign factory.

## Fixed first tranche

Create exactly three independent emulator instances, with save loading disabled
and no cartridge save input. Use the existing qualified opening through starter
acquisition only. No battle policy, fit or campaign progress during this stage.
Each origin is claimed before opening the emulator; retain terminal state on failure.
The fixed IDs are `train-01`, `comparison-01`, `comparison-02`. Their declared
extra boot waits are11,43and79frames respectively. Timing is controlled variation,
**not** the evidence of independence: separate clean initialization, no state-load
calls and an authenticated full creation transcript establish the upstream groups.
Shared cartridge, bootstrap code and teaching procedures remain common factors.

Freeze the private plan (ROM and code identities, assignments and caps) before
creation. Keep the three roots separate from all historical saves and datasets.
Do not open the old sealed comparison pools. Comparison roots are reserved from
all fitting, selection and TRAIN-side debugging. Source-setup inspection may check
structural validity, but must not query a policy or optimize against comparison
outcomes. Freeze candidate/baseline and case selection before policy evaluation.

Assisted descendants may alter explicitly declared party, resources or prerequisites
through revision-pinned teacher adapters. Retain every write and exact parent hash;
never import old save bytes or give the actor a state-editing action. Artificial
story/registration gains and supplied money are not earned outcomes. Native changes
after the declared setup boundary need their own valid admission proof. A root's
creation does not itself establish a runnable lesson or an economic success label.

The existing pilot limits remain24TRAIN lessons (first8stop if fewer than4admitted),
one fit with retention and at most8paired comparisons spanning at least2eligible
comparison groups. Independently initialized roots support this narrow development
screen, not statistical independence of every descendant, unseen-game transfer,
full-player promotion or the old broad8/4lineage gate. No GitHub publication.
