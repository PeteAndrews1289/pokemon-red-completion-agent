# Inspect the project

The dashboard is a read-only spectator. It can show a retained image or checkpoint
after a worker has stopped. An open browser tab, changing engineering text or an
unchanged party is not evidence of a running game or a model fit.

## How to read the display

- Screen and party fields are the last observed native boundary when the feed is idle.
- Registrations are Pokédex credit; party and box contents are separate physical stock.
- Level and XP gains are in-game progress, not fitted model parameters.
- Goal choices, battle choices, automatic mechanics and external engineering are distinct.
- Live partial costs are lower bounds; closed native receipts own final costs and errors.
- Diagnostic-copy XP, captures and wins never become actual-save progress.

A generic party-training label can represent a broader preparation capability.
Inspect the selected binding, intent and closed outcome before diagnosing an XP
loop or assuming a specific Pokémon was chosen by the model.

## Verify activity and results

Before trusting a status claim, authenticate the selected plan, model/package and
worker/supervisor identities. To close a stopped attempt, check the native exit,
released controls, paired save/context and retained partial costs. Preserve the
original error chain; a missing dashboard error is not proof of success.

Recent evidence distinguishes two facts: the switch correction reduces fainting
on three related/exposed wild cases, while the whole evolution/Misty comparison
retains its previous work and XP rather than proving a further speedup. Four
healthy cases keep identical native endpoints. These are DEVELOPMENT results,
not a fresh unchanged campaign or a generalization result.

## Viewer maintenance

The existing viewer is implemented in scripts/run_red_run_dashboard.py. Any
future spectator configuration belongs to its exact selected private run and
must stay view-only. Presentation failure must not silently alter game authority.
There is no need to restart gameplay to refresh documentation or inspect receipts.
