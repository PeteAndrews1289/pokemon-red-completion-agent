# Video outline: teaching an agent to make useful Pokémon decisions

This is an editorial outline, not a completed video or a claim that the project is finished.

## Opening: the honest hook

“I wanted a model that could play Pokémon—not just repeat a walkthrough. Getting code to finish Red turned out to be different from teaching a model useful decisions.”

Show the actual dashboard. Label saved footage as recorded and live footage as live. Do not loop an old frame sequence and present it as current learning.

## Act1 — A teacher is not the final player

Explain why a deterministic teacher helps establish observation, controls and verification. Then show its limitation: overwhelming opponents or following a route can remove the choices the model needs to learn.
