# Coding-assistant comparison record

The coding assistant and the trained Pokémon policy are different models. This
file is not a runtime configuration or a current service-availability/pricing guide.

There is no controlled project experiment establishing that one assistant or effort
setting is superior. Sequential sessions inherit different code, data, blockers and
review feedback. More elapsed work or a successful repair does not isolate the
assistant's contribution or justify an unsupported cost/performance percentage.

The [historical comparison log](history/2026-10-26-coding-model-log-before-documentation-refresh.md)
preserves earlier session observations, failures and quota readings. Those readings
are historical, not current account state. No model setting is changed by this page.

A useful future comparison would predeclare equivalent tasks, starting snapshots,
time/usage measures and outcome criteria, retaining all failures. Such a comparison
must not replace work on the player or run from this document.
