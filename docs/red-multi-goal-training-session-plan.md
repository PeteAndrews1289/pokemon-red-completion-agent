## Mission

The product is a transferable player that can finish Pokémon games and build a living Pokédex.
Red is the first curriculum. The model should choose semantic objectives; deterministic skills
continue to handle controller-level mechanics, verification and safety.

nominal development, with declared providers spanning all nine goal families. That makes the bank
useful for engineering and calibration. It does **not** prove 81 independent experiences. The old
artifacts did not retain a trustworthy upstream-lineage mapping, so the nominal development split
cannot yet support an unseen-generalization claim.

This distinction no longer blocks all useful learning. It changes the label on the evidence:

- existing open train roots may produce **calibration training**;
- existing development roots may provide **same-bank diagnostics**;
- authority promotion and Crystal transfer still require new prospectively partitioned roots.
