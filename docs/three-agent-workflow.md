# Optional collaboration workflow

Codex is the current implementer and verifier. Flash, Claude or subagents may
contribute when Pete gives a current assignment and the work would save effort.
They are not required reviewers, quota checks or session-start prerequisites.

Read [NORTH_STAR.md](../NORTH_STAR.md),
[ACTIVE_PRODUCT_STATE.md](../ACTIVE_PRODUCT_STATE.md) and
[HANDOFF.md](../HANDOFF.md). Current assignments belong only in
[AGENT_COORDINATION.md](../AGENT_COORDINATION.md); none are active now.

Use one source writer at a time. An authorized external draft should have a narrow
scope, explicit writable files and a result to verify. Isolate parallel writes.
Review and integrate the actual changes; do not accept a prose success claim as
proof. Record accepted/rejected findings and any remaining limitations.

Do not launch old Flash packets, check subscriptions, switch the user's selected
model or publish to GitHub on the strength of this document.
No model/service recommendation here is a claim of current availability.

The [earlier collaboration record](history/2026-10-07-collaboration-before-refocus.md)
preserves prior contributions, results and historical usage readings.
