# Bounded sequence collection contract

Historical record, archived October 7, 2026. Not current instructions or an active assignment.

Implementation successor within the approved ROM-free design/test packet. No new
native experiment,fit or adoption is authorized by this file. The ten-step goal
and rejected comparison remain unchanged.

## Mission check

- Capability:collect actual short continuations with pre-choice inputs and costs.
- Authority:observe the existing actor;never choose,replace or force an action.
- Transfer:inputs use existing V6 semantic features plus source-local numeric
  branch history;private objective/context names do not enter candidate vectors.
- Falsifier:a current/future outcome cannot alter its own pre-choice features;
  support belongs to the preceding choice and incomplete windows stay incomplete.
- Time box:finish the collector tests within the design packet before native work.
- Stop:unaccounted input,cross-source history,new scores,rewritten old labels or
  a data window that needs future information to construct its initial features.

## Prospective recorder

An opt-in recorder declares source,partition,behavior-plan hash and a1–4model-choice
horizon before execution. Default runtime behavior is unchanged. It observes only
choices admitted for execution,after the ordinary budget checks. Candidate vectors
are captured before input from the actual policy menu and previously sealed outcome
prefix. Each completed top-level outcome extends that hash-bound prefix once.
It never reads later step directories or a finished run summary to construct history.

The first sampled choice anchors each nonoverlapping window. Deterministic support
adds cost but no fake sampled decision. A full window closes at the next sampled
choice boundary or at run end,so intervening support is not omitted. Leading
support remains outside the first sampled action. The horizon counts actual
model-exploration choices,not successful actions or support steps.

An interrupted/short prefix retains observed costs and a censored label. No
counterfactual target,no whole-quest success for walking,and no replacement for
unselected alternatives. Partial/exceptional native records remain original
evidence;an unprojectable prefix cannot silently become a complete outcome.
