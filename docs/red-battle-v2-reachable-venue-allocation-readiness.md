## Mission fit

The product is a transferable agent that completes stories and builds living
Pokedexes across games. Red is the first curriculum, not the product. This
gate asks one last inexpensive question about the retained Red state bank:
can an independent root supply a genuine battle decision at **any** already
measured venue that the existing bounded executor can reach, rather than only
at the venue implied by the loaded map?

The reusable component is title-neutral. It accepts opaque root identities and
semantic reachable-venue sets, then solves the exact capacitated bipartite
allocation. A later Crystal adapter can expose its own reachable semantic
venues without changing the allocator.

## Contract

- Every root is authenticated, claim-available, unattempted, and used at most
  once.
- A title adapter may offer only venues reachable by an existing bounded live
  transition. It may not add a new arrow sequence.
- Eligibility is re-evaluated independently for every root/venue edge.
- An edge exists only when a living party member is inside that venue's full
  measured encounter-pressure band and has at least two currently PP-positive,
  damaging, non-Selfdestruct actions supported by the learner.
- No healing, resource conditioning, encounter, prediction, outcome, teacher,
  claim, or controller action occurs during readiness inventory.
- The allocator is exact rather than greedy: flexible roots cannot occupy a
  scarce venue in a way that hides a valid assignment.
- Public output contains aggregate counts only. Root identities and selected
  edges remain private and are not diagnostic output.

The Red adapter currently composes only already-implemented transitions:

- a direct measured source retains its direct venue;
- any source that passes the live Vermilion transition predicate can use Route
  11 or Diglett's Cave through the existing ROM-derived recovery callbacks;
- Cinnabar Center and Mansion sources retain their direct Mansion option;
- no generic Mansion route or new field path is inferred.

## Falsifier and stop rule

After publication and exact-head green CI, run one whole-bank, aggregate,
zero-frame V7 census. Capacity passes only if an exact allocation contains at
least seven independent roots, at least two venues, and no more than six roots
at one venue.

Failure ends adaptation of the unchanged retained bank. The successor must
generate genuinely fresh, bounded, authenticated scenario roots with designed
decision pressure. It must not weaken learner action support, relax measured
level pressure, restore PP, inspect selected private failures, reuse exhausted
roots, or patch another retained location.

Pass would open only a separate private freezer/materializer design that binds
the selected root-to-venue edge before controller input. It would not create a
training example, fit a model, open sealed Red or Crystal, grant authority, or
authorize a full-game replay.
