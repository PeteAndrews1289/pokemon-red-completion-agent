# Red battle V2 resource-conditioning readiness contract

Status: locally implemented design; no private census or controller input has run.

Read [MISSION.md](../MISSION.md), [NORTH_STAR.md](../NORTH_STAR.md), and the generated
[active product state](../ACTIVE_PRODUCT_STATE.md) first.

## Question

Can an unused authenticated Red source become a genuine two-action battle lesson after a bounded
resource restoration, without changing the party identity that made the upstream root independent?

This is a supply question, not a learning result. A pass permits a later outcome-blind freeze. It
does not permit a fit, model authority, sealed Red evaluation, Crystal execution, or a replay.

## Portable operation

The title-neutral operation is `restore_battle_resources`. It may restore HP and PP and cure
status. It must preserve, in order:

- every party member's semantic species;
- every party member's level;
- every learned move and move order;
- party order and party size.

The contract requires at least two learner-supported actions after restoration. Red's adapter
counts only cartridge-catalog moves with positive maximum PP, real damaging power, and no
Selfdestruct effect. Current PP is the only learner-support input the readiness projection ignores.
Status moves, one-action parties, level-band failures, and exhausted roots remain rejected.

## Executable Red boundary

Resource restoration uses an existing measured venue's `heal_and_return` behavior. Direct Mansion
and Route 11 sources may take that route only under a future plan that explicitly binds the
conditioning operation. Relocation sources already heal while reaching the venue. The runtime
projects party identity immediately before and after healing and fails closed on any difference.

The Red source adapter now recognizes a generic Route 11 relocation only when the existing live
transition predicate already proves that the exact loaded map, coordinates, badges, living field-
move holder, healing anchor, and tileset support the bounded Vermilion transition. This adds no new
direction string. Red-specific travel remains behind the adapter; later titles implement the same
semantic restoration contract with their own navigation.

## Action-free V6 census

The census must:

1. authenticate the complete historical catalog and retained state bank;
2. authenticate the exact exhausted plan and terminal journal;
3. exclude every source whose assignment ever left `pending`;
4. observe claim availability, map, party, move mechanics, and transition predicates without
   advancing an emulator frame or pressing a controller input;
5. report current two-action capacity separately from full-resource capacity;
6. expose only aggregate map and venue counts;
7. stop unless at least seven independent roots remain across at least two venues after the
   six-per-venue cap.

The census is invalid if it diagnoses a selected private root, changes a party, creates a claim,
materializes an encounter, chooses a move, queries a teacher, opens an outcome, fits a model, opens
sealed Red or Crystal, or grants authority.

## Next gate

Publish the implementation, pass the complete local and exact-head GitHub gates, then run the V6
census once. A failure closes PP restoration as the current-bank supply strategy. A pass opens only
the design and review of a new conditioning-aware freezer and crash-safe materializer; existing
plans remain unchanged and cannot silently opt into conditioning.
