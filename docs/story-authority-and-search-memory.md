## Six-part mission check (before implementation)

1. Capability: preserve measured source-specific search effort across unrelated
   achievements, and identify the actual reusable story-choice components.
2. Learned authority: unchanged frozen Model141 receives correct existing history
   features; no teacher rerouting, masking or forced target. Classify the repair as
   maintenance unblocking the next history-aware integrated learned-choice experiment.
3. Transfer test: ROM-free changes of location, cash, unrelated registrations,
   candidate order, search source and actual remaining targets. These test the
   connection, not native outcome improvement or cross-title generalization.
4. Cheapest falsifier: failed search, unrelated registration, same remaining targets
   produces zero history; or a changed target/source incorrectly inherits that history.
   Authenticate old story artifacts before attempting any native story execution.
5. Time box: one bounded implementation/test session, at most90minutes before
   reassessment. Do not build a new story teacher or run the game to diagnose metadata.
6. Stop condition: regressions pass with unchanged policy weights and retained old
   evidence, or the required change exceeds a narrow history/compatibility repair.
   Story qualification remains open if no compatible genuine-choice path is available.

## Observed bottleneck (#3)

set as their lookup context. Registering Mr. Mime therefore hid previous Safari
effort from the next policy query, although the Safari targets had not changed.
Repair only the future opt-in integrated path: adapters supply a private versioned
remaining-target fingerprint, and the runner uses it consistently for lookup and
recording. Legacy bindings retain the historical fallback; old receipts and fits
are not migrated. New target sets start fresh counters; unrelated progress does not.
No further training is justified merely to repair this information loss.
